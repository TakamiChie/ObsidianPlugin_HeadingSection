# 見出し操作テスト

このノートは Heading Section Tools の手動動作確認用です。
見出し行にカーソルを置くか、見出しへマウスを近づけて操作ボタンを表示してください。

誤クリック防止の確認:
- 最初は「コピー」「レベル変更」「TOC」が表示され、上下の操作が表示されないこと。
- 「レベル変更」をクリックしただけでは本文が変更されず、上下の変更メニューが開くこと。
- 外側のクリックや Esc でメニューを閉じると、本文が変更されないこと。
- メニューで上下を選んだ場合だけ変更され、次の変更には再度「レベル変更」を押す必要があること。
- 「コピー」はメニューを開かずに利用できること。

以下の「↓」「↑」は「レベル変更」のメニューから選んでください。

操作バーのショートカット確認:
- 見出し行で Ctrl + Alt + H を押すと「コピー」にフォーカスすること。
- 本文でバーが非表示の状態から押すと、直前の見出し行へ移動して「コピー」にフォーカスすること。画面外の見出しでも動作すること。
- フォーカス後にマウスを離してもバーが消えず、左右キーと Tab / Shift + Tab でボタンを選べること。
- Enter / Space でコピー・レベル変更・TOC を実行できること。
- Esc で本文に戻り、文字入力を再開できること。
- 最初の見出しより前では、通知のみが表示されること。
- 複数ノートを開いた場合は、操作中のノートのバーにフォーカスすること。

TOC の確認:
- 「TOC」でノート全体の見出しが本文順に表示され、階層の字下げと行番号が見えること。
- 見出しのクリックでウィンドウが閉じ、該当行にカーソルが移動してスクロールすること。
- 上下キーで選択して Enter を押しても同様に移動すること。
- 同名の見出しがあっても、選択した行へ移動すること。
- 検索で一覧を絞り込めること。該当なしの状態で Enter を押しても移動しないこと。
- Esc で閉じるとカーソルが移動せず、本文も変更されないこと。
- コードフェンス内と Setext 形式の見出しが一覧に含まれないこと。

「基本操作 A」のコピーやレベル変更に、この見出しが含まれないことを確認します。

## コードフェンス

次のコードフェンス内にある `#` は、見出しや操作対象として扱われないことを確認します。

```markdown
# コード内のレベル1
## コード内のレベル2
###### コード内のレベル6
```

~~~markdown
### チルダフェンス内の見出し
~~~

### コードフェンス後の見出し

これは通常の見出しとして扱われます。
