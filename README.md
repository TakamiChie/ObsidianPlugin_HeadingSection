# Heading Section Tools

Obsidian の Live Preview 編集画面で、すべての ATX 形式 Markdown 見出し (`#` ～ `######`) の末尾に操作ボタンを追加します。

## 機能

各見出しについて、その見出し行から「次の同じレベルまたは上位レベルの見出し」の直前までを1つのセクションとして扱います。

- **コピー**: セクション全体を Markdown のままクリップボードへコピー
- **レベル変更**: クリックすると上下の変更メニューを表示
  - **↓ 見出しレベルを1つ下げる**: セクション内の全見出しを1段階下げる
  - **↑ 見出しレベルを1つ上げる**: セクション内の全見出しを1段階上げる

見出しへのマウスオーバーやカーソル移動だけでは上下の操作を表示しません。「レベル変更」を押してからメニューの操作を選ぶ2段階で変更します。メニューは外側のクリックや Esc で閉じられます。変更後も、再度「レベル変更」を押してから操作を選びます。

下位見出しも同時に変更するため、セクション内の階層構造を維持します。

例:

```markdown
## 見出しA
本文

### 子見出し
本文

## 見出しB
```

「見出しA」の **レベル変更** → **↓ 見出しレベルを1つ下げる** を選ぶと:

```markdown
### 見出しA
本文

#### 子見出し
本文

## 見出しB
```

## 安全上の動作

- フェンスコードブロック内の `#` は見出しとして扱いません。
- 範囲内に `######` がある状態で **↓** を押した場合、変更しません。
- 範囲内に `#` がある状態で **↑** を押した場合、変更しません。
- Setext形式の見出し (`見出し` + `===`) は現在対象外です。

## インストール

### 開発用

1. このフォルダを Vault の `.obsidian/plugins/heading-section-tools/` に配置します。
2. ターミナルでこのフォルダを開きます。
3. 次を実行します。

```bash
npm install
npm run build
```

4. Obsidian の「設定」→「コミュニティプラグイン」で **Heading Section Tools** を有効にします。

### 配布用

ビルド後は最低限、以下の3ファイルが必要です。

- `main.js`
- `manifest.json`
- `styles.css`

## 対象画面

Live Preview を含む編集モード向けです。
Reading View へのボタン追加は現在行いません。
